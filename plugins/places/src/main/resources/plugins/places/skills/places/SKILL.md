# 她自己的命名地点

你可以把任何一格标上名字记下来,以后自己照着走回去。这些点是你自己的:别的同伴看不见,它们存在
这个存档的世界数据里,换存档各是各的。

这些动作是 `numen.place` 组里的函数。每个怎么写,用 `numen.api.help("numen.place.mark")` 查。

标点:`numen.place.mark("home")` 不带坐标就标你脚下;带坐标就标那一格
(`numen.place.mark("home", {x = 120, y = 64, z = -35})`)。同名同维度再标一次是**覆盖**;
同一个名字在不同维度是两个点。记到别的维度名下必须带全 x/y/z 和 dim,而且那个维度得真的存在。

走回去:`local spot = numen.place.get("home")` 拿到的表可以直接当 `to` 用 ——
`numen.route.plan({to = spot})`。取点缺省取**你现在所在的维度**下的那个;名字在别的维度里标过,
它会告诉你去哪找,但不会替你跨维度。取点这一下会计入"上次用到",点表里的 `last_used` 就是这次的时间。

看存货:`numen.place.list()` 列出你标过的所有点(名字、维度、坐标、距离、上次用到);当前维度的排在前、
由近及远,别的维度排后面,距离是 nil(跨维度没有数可比)。临时找落脚点用
`numen.place.near({radius = 32})`,只看你这个维度、半径以内的,由近及远。

不要的点删掉:`numen.place.forget("old_base")`。删的是你现在维度下的那个;名字在别的维度也有,
它会照实说。

标点、取点都即时完成,不走任务槽。名字是你自己取的,取个下次能认出来的(比如 "home"、"tower_door")。
